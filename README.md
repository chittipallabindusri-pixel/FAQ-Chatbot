# FAQ Chatbot 🤖

## Project Description
FAQ Chatbot is a simple web application that answers frequently asked questions automatically.

## Features
- Interactive chatbot interface
- Automatic question and answer system
- User-friendly design
- Instant responses

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the chatbot website.
2. Type your question.
3. Click the Send button.
4. Get an automatic response.
